# «Ваше название» — общественные дома помощи людям (демо-сайт)

Статический одностраничный сайт (HTML/CSS/JS, без сборки) — демо-концепт сайта сети общественных домов для людей в трудной жизненной ситуации.

- `index.html` — разметка, SEO-мета, JSON-LD
- `styles.css` — стили, адаптив (1080 / 880 / 600 px)
- `script.js` — меню, поиск городов, слайдер отзывов, маска телефона, форма (в демо не отправляет)

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

В демо стоит `noindex`, телефон и ссылки условные. Перед запуском боевой версии уберите его и подключите отправку формы (Telegram-бот / почта).
